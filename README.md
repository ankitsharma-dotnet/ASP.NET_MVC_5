# 🛒 Product Management System

This is a web-based Product Management System developed using ASP.NET MVC, ADO.NET, and SQL Server.

## 🚀 Features
- Add new products
- View product list
- Edit product details
- Delete products
- Feedback form
- Responsive UI using Bootstrap

## 🛠️ Technologies Used
- ASP.NET MVC 5
- ADO.NET
- SQL Server (SQLEXPRESS)
- Bootstrap

## 💡 Project Description
The main objective of this project is to manage product data efficiently. Users can perform complete CRUD operations. The system is designed with a clean and responsive interface for better user experience.

## 📂 Modules
- Product Module (CRUD)
- Feedback Module
